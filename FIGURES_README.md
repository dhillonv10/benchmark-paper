## Layout gate

Every figure is measured before it is saved. The build fails (with `ALLOFM_STRICT_FIGS=1`) if any two
pieces of rendered text overlap, if text sits on a data marker, line or bar, or if any font is below 6 pt.
It sees all rendered text, including multi-line labels. All 11 figures pass under both Liberation Sans and
the wider DejaVu Sans that Colab falls back to (`ALLOFM_FONT="DejaVu Sans"`).

    python3 build/check_figures.py        # runs the notebook's cells and prints one PASS/FAIL line per figure
